Python Code:

from master_system import BazarakiMasterSystem

# Initialize
system = BazarakiMasterSystem()

# Configure service
service_config = {
    'type': 'pool_services',
    'subcategory': 'pool_maintenance',
    'location': 'paphos',
    'buyer_type': 'remote_owner',
    'experience_years': 12,
    'projects_completed': 400,
}

# Images (use real paths in production)
images = [
    '/path/to/image1.jpg',
    '/path/to/image2.jpg',
    '/path/to/image3.jpg',
    '/path/to/image4.jpg',
    '/path/to/image5.jpg',
]

# Generate ad package with Master Prompt Engine
package = system.generate_complete_ad_package(service_config, images)

# View results
print(f"Title: {package.title}")
print(f"Quality: {package.quality_score}")
print(f"Master Prompt Score: {package.master_prompt_score:.1f}%")
print(f"Description Level: {package.master_prompt_level}")
print(f"Status: {package.status}")

# Save to JSON
system.save_package_to_json(package, 'ad_package.json')

================================================================================
🐛 TROUBLESHOOTING
================================================================================

Issue: "Master Prompt Engine not found"
├─ Solution: Verify master_prompt_engine.py is in same directory as master_system.py
└─ Check: Python can import the module

Issue: "Quality score is low (< 75%)"
├─ Solution 1: Check if images are real and high quality
├─ Solution 2: Verify service type is correctly configured
└─ Solution 3: Check market_data for service type

Issue: "Images not verifying"
├─ Solution: Use real high-quality images (1024x768 minimum)
├─ Ensure images match service type (pool images for pool services)
└─ No watermarks, logos, or text overlays

Issue: "System runs slowly"
├─ Solution: Disable unused services in config.json
├─ Check: Internet connection for market data
└─ Verify: No antivirus blocking image processing

Issue: "Descriptions don't pass quality gates"
├─ Solution: Ensure all 5 images are verified
├─ Check: Service type and location are set correctly
└─ Verify: Experience years and projects are reasonable

Issue: "JSON export fails"
├─ Solution: Check output folder has write permissions
├─ Verify: Folder exists and is writable
└─ Ensure: Enough disk space
