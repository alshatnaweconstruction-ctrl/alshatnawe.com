## 🚀 DEPLOYMENT GUIDE

### Prerequisites
- Python 3.8+
- SQLite3
- No external dependencies

### Installation

```bash
# Extract all files to BAZARAKI_V4 directory
cd BAZARAKI_V4

# Copy all Python files
cp *.py ./

# Initialize database (automatic on first run)
python master_system_v4.py
```

### Windows Deployment
```batch
# Create Task Scheduler task
# Command: python C:\BAZARAKI_V4\master_system_v4.py
# Schedule: Daily at 08:00 AM
# User: SYSTEM (for 24/7 execution)
```

### Linux/Mac Deployment
```bash
# Add to crontab
crontab -e

# Add line:
0 8 * * * cd /path/to/BAZARAKI_V4 && python master_system_v4.py
```

## 📞 SUPPORT & TROUBLESHOOTING

### Common Issues

**Issue:** Master Prompt Engine not generating descriptions
- **Solution:** Verify master_prompt_engine.py is in same directory
- **Check:** Import statement works correctly

**Issue:** Image verification scores too low
- **Solution:** Ensure images are real, high-quality, authentic
- **Check:** No stock photos, no heavy filters, no watermarks

**Issue:** Pricing calculations seem off
- **Solution:** Verify location and service type match Cyprus market
- **Check:** Use correct location names (lowercase)

**Issue:** Database connection errors
- **Solution:** Check SQLite3 installation and database path permissions
- **Check:** Ensure /tmp/ directory is writable

**Issue:** Performance predictions inaccurate
- **Solution:** Provide more historical data for training
- **Check:** Wait 30 days of data before optimization
