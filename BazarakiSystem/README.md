## 🎯 البدء السريع

### التثبيت (Windows):

```bash
# 1. استنساخ أو تحميل المستودع
git clone https://github.com/YOUR_USERNAME/bazaraki-autonomous-system.git
cd bazaraki-autonomous-system

# 2. تثبيت المتطلبات
pip install -r requirements.txt

# 3. تشغيل النظام
python master_system.py
```

### التشغيل الأول:

```python
from master_system import BazarakiMasterSystem

# إنشاء النظام
system = BazarakiMasterSystem()

# إعداد الخدمة
config = {
    'type': 'pool_services',
    'subcategory': 'pool_maintenance',
    'location': 'paphos',
    'buyer_type': 'remote_owner',
    'experience_years': 12,
    'projects_completed': 400
}

# الصور (يجب أن تكون موثقة ومتحققة)
images = [
    'data/images/pool_1.jpg',
    'data/images/pool_2.jpg',
    'data/images/pool_3.jpg',
    'data/images/pool_4.jpg',
    'data/images/pool_5.jpg'
]

# إنشاء الإعلان الكامل
package = system.generate_complete_ad_package(config, images)

# الحفظ
system.save_package_to_json(package, 'output/ad_package.json')
```
